## 🚀 **Setup Instructions**

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn package manager

### Installation
```bash
cd porfolio
npm install
```

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
